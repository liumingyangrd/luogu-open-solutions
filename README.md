# 洛谷「可发题解」题目速查

一个单文件网页：列出**当前题解提交通道仍处于开放状态**的洛谷题目，共 7956 道（快照 2026-10-27），支持按难度分档筛选、按题号 / 标题 / 标签搜索，点题号直达洛谷题目页。

**在线访问（GitHub Pages）**：https://liumingyangrd.github.io/luogu-open-solutions/

## 这是什么原理？

洛谷对题解数量过多的题目会自动关闭题解提交通道（提交时提示「不能提交该题题解」），想发题解只能挑还没关的题。第三方存档站[「洛谷档案馆」](https://www.luogu.ac.cn)（开源项目 [lga-team/luogu-archive](https://github.com/lga-team/luogu-archive)）持续爬取并追踪每道题的「题解开放状态」，本仓库把它的接口数据做成了离线可用的速查页。

各难度档收录数量（2026-10-27 快照）：

| 难度 | 可发题解题目数 |
| --- | --- |
| 普及 | 358 |
| 普及+/提高- | 1108 |
| 提高 | 1732 |
| 提高+/省选- | 157 |
| 省选/NOI- | 2628 |
| NOI/NOI+/CTSC | 1627 |
| 暂无评定 | 346 |
| **合计** | **7956** |

> 「入门 / 普及-」两档暂无收录（基本都已被关闭题解通道）。

## 更新数据

```bash
python update_data.py   # 重新拉取 API 并生成 index.html，然后提交推送即可
```

数据源接口（可直接在浏览器打开查看实时数据）：

- 总览：`https://www.luogu.ac.cn/api/v1/problem/list?preview_limit=20`
- 单档全量：`https://www.luogu.ac.cn/api/v1/problem/list/by-difficulty?difficulty=省选/NOI-`（`difficulty` 需 URL 编码，`/` 也要编码，否则返回空）

注意：接口有 CORS 限制（仅允许站点自身域名），所以页面采用「离线快照」而非浏览器实时拉取；档案馆目录全量抓取于 2026-08-30，各题状态按难度分档持续轮询，可能与洛谷实时状态有短暂出入，**发题解前请以题目页实际显示为准**。

## 文件

- `index.html` — 速查页（单文件，无依赖，可直接双击打开或部署到任意静态托管）
- `update_data.py` — 数据更新脚本
